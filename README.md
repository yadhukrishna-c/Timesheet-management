# ⏱ Timesheet Management System

A full-stack MERN application for managing employee work hours, projects, and real-time productivity tracking.

## 🚀 Live Features

- 🔐 JWT-based authentication with role-based access (Admin & Employee)
- 👥 Admin dashboard to manage employees and projects
- ⏱ Real-time work tracking with Start/Stop timer
- 📊 Live employee online/offline status monitoring
- 📋 Project assignment with deadlines
- 📝 Work report submission
- 🕐 Daily work hours summary per employee

---

## 🛠 Tech Stack

### Backend
- **Node.js** — Runtime environment
- **Express.js** — REST API framework
- **MongoDB** — NoSQL database
- **Mongoose** — MongoDB object modeling
- **JWT** — Authentication tokens
- **bcryptjs** — Password hashing

### Frontend
- **React.js** — UI library
- **React Router DOM** — Client-side routing
- **Axios** — HTTP requests
- **Context API** — Global state management
